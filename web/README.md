# yt-dl-agent web UI

A React + [shadcn/ui](https://ui.shadcn.com) (Base UI, `base-nova` style) front end for the CLI. Users run
it with `yt-dl-agent serve` (see the main [README](../README.md#web-ui)). This file is for working on it.

| Screen | Route | Backend |
|---|---|---|
| Request & queue | `/` | `chat.parse_line` → "I understood" → `chat.DownloadQueue`; profile links use `sources.user_playlists`; Options = the run flags of `cli.main` |
| Songs | `/library` | every cached collection, joined into one row per file |
| Playlists & albums | `/playlists`, `/playlists/:id` | `songs/.cache/<id>.json`; Sync = queue the link again |
| Import files | `/import` | `importer.run_import` (Preview = dry run), history and `importer.undo` |
| Unsorted | `/unsorted` | `.cache/unsorted.json` |
| Fix library | `/fix` | `fixer.run_fix` (Preview = dry run) |
| Run logs | `/logs` | `logs/run-*.log` |
| Settings | `/settings` | service checks, `.env`, `YTDL_*` run defaults (`config.py`) |
| Help & docs | `/help` | in-app documentation; each page's (?) links to `/help#<topic>` |

- `src/lib/types.ts` mirrors the Python models and states field for field. Change it first when the
  backend changes.
- `src/lib/api.ts` is the HTTP contract: one method per endpoint in `src/yt_dl_agent/server.py`, each
  naming the Python function it wraps. `mockApi` implements the same interface on `src/lib/mock.ts`.

## Develop

```bash
npm --prefix web install
```

On sample data (no Python needed; the queue simulates a worker, and the sidebar says "sample data"):

```bash
npm --prefix web run dev
```

Against your real library: start `yt-dl-agent serve` in another terminal, then:

```bash
npm --prefix web run dev:live
```

Vite proxies `/api` to `127.0.0.1:8765`. The mode comes from `VITE_API` (`.env.live` sets `http`). A
production build always uses the real API.

## Build

```bash
npm --prefix web run build
```

`yt-dl-agent serve` serves `web/dist` when it exists. Restart it after a build.

## Notes

- Components in `src/components/ui/` are generated by the shadcn CLI. Two are patched: `button.tsx`
  sets `nativeButton={false}` when rendered as a link, and `scroll-area.tsx` drops an unused import.
- Base UI composes with `render={<NavLink … />}`, not Radix's `asChild`. A `Select` needs `items` to show
  labels rather than raw values.
- Status colours are the `success` / `warning` / `info` tokens in `src/index.css`, defined for light and
  dark mode.
